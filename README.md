# Эмулятор виртуальной файловой системы (VFS)

Программа эмулирует работу командной строки Unix-подобной ОС с виртуальной файловой системой, загружаемой из формата JSON.

## Особенности

* Графический интерфейс пользователя на базе Tkinter.
* Загрузка VFS из JSON файла.
* Автоматическое выполнение команд из стартового скрипта при запуске.
* Поддержка переменных окружения (`$HOME`, `%USER%` и др.).

## Поддерживаемые команды

* `ls` — просмотр содержимого директории.
* `cd` — смена текущей директории.
* `tac` — вывод содержимого файла в обратном порядке строк.
* `cal` — вывод календаря на текущий месяц.
* `chown` — смена владельца/группы у объекта VFS.
* `mv` — перемещение или переименование файлов и папок.
* `conf-dump` — дамп текущей конфигурации приложения.
* `exit` — завершение работы программы.

## Требования

* Python 3.10+

## Запуск приложения

Запуск эмулятора с передачей путей к файлу VFS и стартовому скрипту:

```bash
python main.py --vfs-path vfs.json --script-path script.txt
```

## Запуск тестов

Для проверки работоспособности всех команд выполните unit-тесты:

```bash
python -m unittest test_main.py
```
